# DSH MCP Manager

简体中文 | [English](./README.en.md)

`dsh-mcp-manager` 在 DeepSeek Harness（DSH）侧栏增加 **MCP 服务器** 管理面板，并提供配套工具 `mcp_servers_manage`。当你想用表单代替手写 YAML 来配置远程 Streamable HTTP 或本地 stdio MCP 服务器、在保存前预览生成结果并管理连接状态时，可以使用这个插件。

## 安装插件

1. 在目标 DSH 应用中打开 **插件 → 添加插件**。
2. 选择 Git 来源，填入：

```text
github:null0xfff/dsh-mcp-manager
```

安装并启用后，从侧栏打开 **MCP 服务器** 面板。所有配置通过 DSH 原生 Settings 接口保存，作用于当前 profile 下的所有会话；服务器备注按 profile 单独持久化。

## 首次使用（只读预览练习）

下面这段练习不会写入配置，也不会连接任何服务器：

1. 点击 **添加服务器**。
2. 名称填入 `demo-http`。
3. 连接方式选择 **HTTP**，端点填入 `https://example.invalid/mcp`（该保留域名仅用于演示）。
4. 保持 **保存后启用连接** 为关闭状态。
5. 点击 **校验并预览**，展开只读预览查看生成的配置。
6. 确认无误后，点击 **取消** 结束练习。

## 配置真实服务器时的行为说明

对真实服务器进行操作时，以下三个动作会触发完全不同的行为：

- **校验并预览**：表单先检查输入，再由 DSH 宿主生成只读配置预览。
- **保存服务器**：通过 DSH 原生 Settings 持久化配置，影响当前 profile 的所有会话；若开启了 **保存后启用连接**，保存后会自动尝试连接。
- **测试连接**：实际发起 MCP 握手并读取服务器提供的工具列表。如果目标是本地 **stdio** 服务器，测试连接可能会启动对应程序。

填写本地 **stdio** 服务器时，程序路径与参数分开填写，参数框中**每行一个参数**。

## 凭据与协议支持

- **凭据引用**：请求头和环境变量支持使用 DSH 已有的凭据引用语法，例如 `Bearer ${credential:MCP_TOKEN}`。插件本身不创建或托管凭据记录。
- **明文提示**：如果直接在表单中填写明文密钥，即使预览界面已作遮盖处理，该明文仍可能保存在 profile 配置中。
- **支持范围**：仅支持 **Streamable HTTP** 与 **stdio**；旧式 SSE 与交互式 OAuth 不在支持范围内。

## 权限说明

插件分别对管理界面与 Agent 工具实施权限边界：

- **界面权限**：只有已认证的 `owner` 可以通过界面管理配置；`viewer` 访问管理接口会收到 `403`。
- **Agent 工具权限**：工具名为 `mcp_servers_manage`：
  - **只读操作**：`list`、`preview`。
  - **变更与连接操作**：`save`（保存）、`toggle`（用 `enabled: true` 或 `false` 控制启停）、`remove`（删除）、`reset`（重置覆盖）、`probe`（探测）、`restart`（重连）以及 `note`（修改备注），均要求存在明确的调用会话且会话权限为 **Full access**。缺少会话或无法确认权限时，插件会拒绝执行。

## 兼容范围与开发验证

- **当前版本**：`1.1.3`
- **Node.js**：`>=24.9.0`
- **DSH 兼容范围**：`>=0.2.2-rc.3 <0.2.3-0`
  - **已实测**：已在 `0.2.2-rc.3`、`0.2.2-rc.4` 与 `0.2.2-rc.5` 上验证宿主加载、`owner`/`viewer` 权限隔离、配置写入、备注持久化与客户端注册。
  - **版本策略**：同一 `0.2.2` 线的后续版本按兼容策略准入。
- **运行时依赖**：`yaml` `2.8.1`、`zod` `4.6.6`。

开发者可在仓库根目录运行以下命令安装依赖并执行测试：

```sh
pnpm install --frozen-lockfile
pnpm test
```
